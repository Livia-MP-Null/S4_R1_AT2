
## Explique o que é uma interface.

A interface é um modelo qual os objetos seguem uma padrão que devem conter em todos como um modelo base a ser seguido. por exemplo o controle, computadores, celulares tudo tem um modelo.A interface padroniza os métodos e obriga os repositórios  e classes a implementar todos eles.


## Diferença entre classe abstrata e interface

A classe abstrata como um molde já meio pronto que passa
 código e características em comum para classes parecidas, mas
  você só pode escolher um molde por vez. Já a interface é só
   uma lista de regras dizendo o que a classe tem que fazer, 
  sem dar nada pronto, e uma mesma classe pode seguir várias 
  dessas listas ao mesmo tempo.

## Por que interfaces ajudam no trabalho em equipe

No dia a dia do time, a interface funciona como um combinado
 prévio de como as peças do código vão se encaixar. Com esse 
 combinado na mão, cada dev consegue programar e testar a sua 
 parte ao mesmo tempo, sem precisar esperar o colega terminar
  e sem correr o risco de uma mudança sua quebrar o código do 
  outro.
